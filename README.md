# Лабораторна робота: множина рядків на хешуванні (варіант 2)

Завдання: реалізувати структуру даних «множина рядків». Рядки – непусті послідовності довжиною до 15 символів з рядкових латинських літер. Структура підтримує додавання рядка, вилучення та перевірку належності. Кількість рядків у множині не більше 10^6, кількість операцій у вхідному файлі теж не більше 10^6.

Вхідні дані – кожен рядок задає одну операцію: `+ слово` (додати), `- слово` (вилучити), `? слово` (перевірити). Список операцій завершується рядком `#`. На кожну операцію `?` виводиться yes або no.

Варіант 2: знайти усі паліндроми в множині рядків і оцінити час виконання. Після `#` програма виводить кількість паліндромів і їх список за абеткою.

Множина зроблена як хеш-таблиця з ланцюгами, для рядків використовується подвійний поліноміальний хеш. Опис рішення та оцінка часу – у файлі REPORT.md.

Файли:
- `string_set.h` – клас множини
- `main.cpp` – основна програма
- `gen.cpp` – генератор вхідних даних
- `brute.cpp` – простий розв'язок на std::unordered_set для перевірки правильності
- `input_example.txt` – приклад входу

Збірка (g++):

```
mkdir build
g++ -O2 -std=c++17 -static main.cpp -o build\lab.exe
g++ -O2 -std=c++17 -static gen.cpp -o build\gen.exe
```

Запуск:

```
build\lab.exe input_example.txt
build\gen.exe 100000 7 > test.txt
build\lab.exe -t test.txt out.txt
```

Ключ `-t` виводить час роботи і розмір таблиці.

Генератор вхідних даних:

```
gen.exe N seed [add del ask] [pool] [pal]
```

| Параметр | Що означає | За замовчуванням |
|---|---|---|
| N | кількість операцій (рядків у файлі), не більше 10^6 | обов'язковий |
| seed | зерно генератора випадкових чисел: однаковий seed дає однаковий файл | обов'язковий |
| add del ask | ваги операцій `+`, `-`, `?` (у відсотках) | 50 20 30 |
| pool | скільки різних слів використовується у файлі | N/3 |
| pal | який відсоток слів у пулі будується як паліндроми | 10 |

Параметри позиційні: необов'язкові можна не писати лише з кінця, а три ваги задаються разом. Слова беруться з обмеженого пулу, щоб у файлі були повторні додавання, вилучення відсутніх рядків і відповіді як yes, так і no. Паліндроми генеруються окремо (випадкова половина + її дзеркало), бо випадковий довгий рядок майже ніколи не буває паліндромом.

Приклади:

```
gen.exe 20 1 50 20 30 8 50 > small.txt
```
20 операцій, лише 8 різних слів, половина з них паліндроми – маленький файл, який видно на екрані, зі всіма видами операцій.

```
gen.exe 100000 7 > test.txt
```
100 000 операцій зі стандартними параметрами – для заміру часу.

```
gen.exe 100000 1 100 0 0 100000 10 > big_set.txt
```
тільки додавання з пулу 100 000 слів – у множині виходить близько 55 000 різних рядків (вимога умови – 10^4–10^5).

Перевірка правильності (вивід двох програм на одному файлі має збігатися):

```
g++ -O2 -std=c++17 -static brute.cpp -o build\brute.exe
build\lab.exe test.txt out.txt
build\brute.exe test.txt out_brute.txt
fc out.txt out_brute.txt
```
